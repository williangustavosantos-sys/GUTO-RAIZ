# GUTO V3 — Start Here

Você está trabalhando no GUTO V3.

Antes de alterar qualquer código, leia todos os arquivos desta pasta na ordem numérica.

Não assuma que código legado representa a arquitetura atual.

Git + estes documentos + testes atuais são a fonte operacional do projeto.

O GUTO não é apenas um fitness app, chatbot ou personal digital. É um companheiro ativo digital: possui personalidade própria e fixa, toma iniciativa, constrói memória longitudinal e decide dentro de uma autoridade explicitamente delimitada.

Princípios de produto que afetam o código:

- personalidade e presença fazem parte do contrato do produto;
- proatividade e consequências reais devem respeitar autoridade, consentimento e estado persistido;
- treino e nutrição oficiais são decisões determinísticas;
- Gemini interpreta, raciocina e fala, mas não é autoridade matemática nem verdade oficial;
- memória longitudinal não pode criar uma segunda fonte de verdade;
- decisões contrárias ao padrão do mercado devem ser testadas antes de serem normalizadas ou removidas;
- um teste verde não substitui a jornada real no navegador nem o aceite do fundador.

Comece por `01-CURRENT-STATE.md`. Se o Git real divergir deste snapshot, pare e registre a divergência antes de desenvolver.
